# Tetris (MonoGame)

C#とMonoGameを用いて一から構築した、2Dパズルゲーム『テトリス』の個人開発。

## 作品コンセプト：
ゲームが動く基本的な仕組みや裏側のロジック理解して構築するために開発。
## 技術スタック：
MonoGame, C# , JetBrains Rider
ライブラリなどの機能に頼らず、プログラミングのロジックと数学的なアプローチを利用。

## ソースコード：

- **[Game1.cs](tetris/Game1.cs)**
    - 毎フレームの状態更新Updateと描画Drawを管理。
    - ブロックが接地した瞬間に画面を揺らすシェイク演出や、ライン消去時のフラッシュ演出のフラグ管理など。

- **[Board.cs](tetris/Board.cs)**
    - 盤面の状態を管理するファイル。画面の描画とは完全に切り離し、10×20マスの2次元配列データとして盤面を保持。
    - ブロックの衝突の検知や、ラインが揃ったときの消去など。

- **[Mino.cs](tetris/Mino.cs)**
    - テトリミノの形や動きを制御するファイル。
    - ブロックの回転において、行列変換の考え方を用いてロジックで動的に計算・回転。

- **フレームワーク:** MonoGame
- **IDE:** JetBrains Rider
