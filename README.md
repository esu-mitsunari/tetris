# Tetris (MonoGame)

C#とMonoGameを用いて一から構築した、2Dパズルゲーム『テトリス』の個人開発。

## 作品コンセプト：
ゲームが動く基本的な仕組みや裏側のロジックを、一から自分の手で理解して構築するために開発。
## 技術スタック：
MonoGame, C# , JetBrains Rider
ライブラリなどの機能に頼らず、プログラミングのロジックと数学的なアプローチだけで組み立てました。

## ソースコード：
コードの設計は、役割ごとにクラスを明確に分離（オブジェクト指向）することを意識しています。

- **[Game1.cs](tetris/Game1.cs)**
    - 毎フレームの状態更新Updateと描画Drawを管理しています。
    - ブロックが接地した瞬間に画面を揺らすシェイク演出や、ライン消去時のフラッシュ演出のフラグ管理など、ゲーム進行の起点となるファイル。

- **[Board.cs](tetris/Board.cs)**
    - 盤面の状態を管理するファイル。画面の描画とは完全に切り離し、10×20マスの純粋な「2次元配列データ」として盤面を保持。
    - ブロックの衝突の検知や、ラインが揃ったときの消去など。

- **[Mino.cs](tetris/Mino.cs)**
    - テトリミノの形や動きを制御するファイル。
    - ブロックの回転において、行列変換の考え方を用いてロジックで動的に計算・回転。
